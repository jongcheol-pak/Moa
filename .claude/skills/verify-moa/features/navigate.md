# 주소창 탐색

사용자는 주소창에 경로를 쳐서 그 폴더로 가고, 뒤로·앞으로·위로 화살표로 이동한다. 이동하면 탭 이름이 폴더 이름으로 바뀌고 사이드바의 워크스페이스 항목 둘째 줄 경로도 따라 바뀐다. 없는 경로를 치면 현재 위치에 머문다.

## Sub-features

- `nav-path` — 주소창에 경로를 입력하고 Enter 로 이동한다.
- `nav-invalid` — 없는 경로는 이동하지 않고 현재 위치를 지킨다.
- `nav-back-forward` — 뒤로·앞으로(화살표 버튼, `Alt+←`/`Alt+→`).
- `nav-up` — 위로(화살표 버튼, `Alt+↑`, 목록 첫 줄 `..` 더블클릭).

## How to get to it (user POV)

- 주소 줄 가운데 경로 입력란을 클릭 → 전체 선택 → 경로 입력 → Enter.
- 주소 줄 왼쪽 화살표 버튼 셋(뒤로·앞으로·위로).
- 목록에 포커스가 있을 때 `Alt+←`·`Alt+→`·`Alt+↑`.
- 목록 첫 줄 `..` 더블클릭.

## Driving it with karina-cli

Preconditions:

- `doctor.ps1` 이 `DOCTOR: OK`. 빈 설정이면 첫 탭이 사용자 홈을 연 상태다.

- **경로 입력.** 주소 줄의 경로 입력란(탭 줄 바로 아래 줄, 화살표 셋 오른쪽의 긴 칸)을 `click --restore-window` 로 클릭하고 `hotkey --key CmdOrCtrl+A`, `type-text --text <run.workDir>`, `press-key --key Return`. 1초 뒤 `shot.ps1 -Name <n>-nav-path`. 탭 이름이 `work`, 입력란이 그 경로, 목록이 `..` 한 줄과 `이 폴더는 비어 있습니다`, 상태 줄이 `폴더 0 파일 0`, 사이드바 워크스페이스 경로가 바뀐다.
- **없는 경로.** 같은 방법으로 `<run.workDir>\does-not-exist` 를 입력한다. 캡처에서 탭 이름과 목록이 직전과 같다.
- **위로.** 주소 줄 셋째 화살표(위쪽)를 클릭한다. 탭 이름이 실행 폴더 이름(`<RunId>`)으로 바뀌고 목록에 폴더 `app`·`evidence`·`work` 와 파일 `run.json` 이 보이고, 상태 줄이 `폴더 3 파일 1` 이다.
- **뒤로·앞으로.** 첫째 화살표(왼쪽)를 클릭하면 `work` 로 돌아오고, 둘째 화살표(오른쪽)를 클릭하면 다시 실행 폴더로 간다. 각 단계를 캡처한다.
- **`..` 더블클릭.** 목록 첫 줄 `..` 이름 위를 빠르게 두 번 클릭한다(`click` 두 번). 위로와 같은 결과다.

## Gotchas

- 주소창 클릭만으로는 기존 경로가 남아 있다 — `CmdOrCtrl+A` 로 전체 선택한 뒤 친다.
- 입력란 밖에 포커스가 있으면 `type-text` 가 목록의 이름 찾기 등으로 들어간다 — 입력 뒤 캡처에서 입력란 글자를 확인한다.
- 사용자 홈 목록이 증거에 찍히지 않게, 첫 캡처 전에 `work\` 로 옮긴다.
- 2026-10-19 증명: `nav-path` 통과. 나머지 하위 기능은 아직 조작하지 않았다.
