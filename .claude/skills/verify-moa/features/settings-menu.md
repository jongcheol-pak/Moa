# 설정 메뉴·설정 화면

사용자는 타이틀바 톱니 버튼으로 설정 메뉴를 열어 `설정`·`업데이트`·`릴리즈 노트`·`오픈소스 라이선스`·`정보` 를 고른다. `설정` 대화의 바꾼 값은 확인 버튼 없이 곧바로 반영·저장된다.

## Sub-features

- `menu-open` — 톱니 버튼으로 설정 메뉴를 연다.
- `settings-dialog` — `설정` 으로 설정 대화를 열고 닫는다.
- `settings-toggle` — `파일 보기` 의 토글(예: 파일 확장명 표시)을 바꾸면 목록과 `settings.json` 에 반영된다.
- `about` — `정보` 로 앱 이름·버전 팝업을 연다.
- `licenses` — `오픈소스 라이선스` 대화를 연다.

## How to get to it (user POV)

- 타이틀바 오른쪽, 최소화 버튼 왼쪽의 톱니 아이콘 → 메뉴 항목.

## Driving it with karina-cli

Preconditions:

- `doctor.ps1` 이 `DOCTOR: OK`. 개발 사본이라 `업데이트` 항목은 흐리게(비활성) 보인다.

- **메뉴 열기.** 타이틀바 오른쪽 톱니 아이콘을 `click --restore-window` 로 클릭하고 `shot.ps1 -Name <n>-menu-open -NoRaise`. 톱니 아래로 `설정`·`업데이트`(흐림)·`릴리즈 노트`·구분선·`오픈소스 라이선스`·`정보` 가 보인다.
- **정보.** 메뉴의 `정보` 를 클릭하고 `-NoRaise` 로 캡처한다. 앱 아이콘과 `모아 <Cargo.toml 의 version>` 한 줄, 저작권·라이선스·저장소 세 줄이 보인다. 버전이 `Cargo.toml` 의 `version` 과 같은지 본다.
- **설정 대화.** 메뉴의 `설정` 을 클릭하고 캡처한다. `모양`·`시작`·`종료`·`언어`·`파일 보기`·`원격` 묶음과 `닫기` 가 보인다.
- **토글 반영.** `work\` 에 파일이 있는 상태(`create-item.md` 의 `새 파일`)에서 `파일 보기` 의 `파일 확장명 표시` 토글을 클릭한다. 대화를 `닫기` 로 닫고 캡처하면 목록 이름에서 확장자가 빠져 있다. `settings.json` 의 해당 값이 바뀐다.

## Gotchas

- `시작` 의 `윈도우 시작 시 실행` 토글은 `HKCU\...\Run` 의 `MOA` 값을 실행 사본 경로로 바꾼다 — 사용자 설치본의 자동 실행을 망가뜨리므로 조작하지 않는다.
- `릴리즈 노트`·`정보` 의 저장소 줄은 브라우저를 연다(외부 이동) — 누르지 않는다.
- 메뉴·팝업은 창 최소화·복원에 닫힌다 — 열린 상태는 `-NoRaise` 로 찍는다.
- 2026-10-19 증명: `menu-open` 통과(메뉴 항목 확인). 나머지 하위 기능은 아직 조작하지 않았다.
