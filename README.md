# MOA — 멀티 분할 경량 파일 탐색기

Windows 11 이상(x64)에서 하나의 창을 **자유 분할(트리형)**하고, 각 패널이 **독립 탭**을 가지며, 좌측 **워크스페이스 목록**으로 여러 벌의 탐색기 화면을 전환하는 초경량 파일 탐색기입니다. UI는 Rust의 egui(eframe/glow)로 직접 그리고, 아이콘·컨텍스트 메뉴·변경 감시·파일 실행 같은 셸 연동은 windows-rs로 Win32 API를 호출합니다 (Q-Dir의 멀티 패널 + VS Code의 자유 분할 UX 참고). **FTP·FTPS·SFTP 원격 서버**를 로컬 폴더와 같은 패널·탭에서 다룹니다.

## 핵심 기능

- **워크스페이스**: 좌측 사이드바에서 워크스페이스를 만들면(`+` 버튼) 그 워크스페이스만의 탐색기 화면이 생기고, 항목을 고르면 즉시 전환됩니다. 워크스페이스마다 분할 구성·패널·탭·히스토리가 완전히 독립이며, 항목은 이름과 현재 폴더 경로를 2줄로 보여줍니다. 이름 바꾸기(`F2`·우클릭), 삭제(확인 후 — 마지막 1개는 불가), 드래그로 순서 변경을 지원합니다
- **사이드바 조절**: 경계선 드래그로 폭 변경(160~480px), `Ctrl+B`·**타이틀바 왼쪽 버튼**으로 접기/펼치기 (접힌 상태·폭도 저장됩니다)
- **커스텀 타이틀바**: 창 제목 표시줄을 앱이 직접 그립니다 — 왼쪽에 앱 아이콘과 워크스페이스 목록 표시 토글, 가운데에 활성 워크스페이스 이름, 오른쪽에 설정 메뉴와 최소화·최대화·닫기 버튼. 앱 아이콘은 `docs/AppIcon.ico` 한 장으로 타이틀바·작업 표시줄·실행 파일이 모두 같은 그림을 씁니다. 타이틀바 빈 영역을 끌어 창을 옮기고(화면 가장자리 스냅 지원), 더블클릭으로 최대화/복원하며, 창 가장자리·모서리를 끌어 크기를 바꿉니다. 설정 메뉴(⚙)에는 `설정 · 업데이트 · 릴리즈 노트 · 오픈소스 라이선스 · 정보`가 있고 **다섯 항목이 모두 동작합니다** — `설정`은 아래의 설정 화면을, `업데이트`는 새 버전 확인을(아래 「자동 업데이트」), `릴리즈 노트`는 브라우저로 GitHub 릴리즈 페이지를, `오픈소스 라이선스`는 라이선스 고지 화면을, `정보`는 앱 정보 화면을 엽니다. OS 장식을 끈 대신 창 그림자·둥근 모서리와 Windows 11 스냅 레이아웃 팝업(최대화 버튼 호버 메뉴)은 없습니다. 최대화·복원·최소화는 OS 전환 애니메이션 없이 곧바로 바뀝니다 — 그 애니메이션이 바뀌기 전 화면과 새 화면을 겹쳐 페이드해 글자가 이중으로 보였기 때문입니다
- **설정 화면**: 타이틀바 설정 메뉴(⚙)의 `설정`으로 여는 대화이며, 여섯 묶음이 한 화면에 있습니다(항목이 창보다 길면 본문만 스크롤되고 제목·`닫기`는 제자리에 남습니다). **바꾸는 즉시 반영되고 저장됩니다**(확인 버튼 없음).
  - `모양` — **글꼴**: PC에 깔린 글꼴 중 **한글을 실제로 그리는 것만** 골라 목록에 냅니다(목록은 앱이 시작할 때 백그라운드에서 미리 읽어 둡니다 — 대화를 열면 대개 곧바로 나옵니다). 고르면 곧바로 앱 전체 글꼴이 바뀌고, `기본값 (맑은 고딕)`으로 되돌릴 수 있습니다
  - `시작` — **윈도우 시작 시 실행**: 켜면 `HKCU\…\Run`에 등록합니다(관리자 권한 불필요). 트레이 토글이 함께 켜져 있으면 부팅 시 **창 없이 트레이로만** 올라옵니다
  - `종료` — **닫으면 트레이로 보내기**: 켜면 ① 트레이 아이콘이 창이 떠 있는 동안에도 보이고 ② 닫기(`✕`)가 종료 대신 창을 숨기며 ③ 아이콘 더블클릭이 창을 다시 최상위로 띄우고 ④ 아이콘 우클릭에 `열기`·`종료` 메뉴가 붙습니다. 창을 숨길 때도 세션을 저장합니다
  - `언어` — **앱 언어**: `시스템 기본`·`한국어`·`English` 중에서 고르면 **다음 프레임부터** 모든 화면 문구가 바뀝니다(재시작 불필요). `시스템 기본`은 Windows 사용자 UI 언어가 한국어면 한국어, 아니면 영어입니다. 드롭다운 항목 이름도 지금 언어를 따릅니다. **창 밖에 보이는 두 이름도 함께 바뀝니다** — 창 제목(작업 표시줄·Alt+Tab)과 트레이 아이콘 툴팁이며, 앱 이름은 한국어에서 `모아`, 영어에서 `MOA`입니다(설정 파일·자동 실행 등록 이름은 바뀌지 않습니다). **다만 이미 떠 있는 실패 사유**(연결·전송)는 실패한 순간의 언어로 남고 다음 실패 때 새 언어로 나옵니다
  - `파일 보기` — 토글 셋입니다. **파일 확장명 표시**(끄면 목록에서 이름 뒤 확장자를 뗍니다 — 폴더·`..`·확장자 없는 파일은 그대로) · **숨김 파일 및 폴더 표시**(끄면 숨김 속성이 붙은 로컬 항목과 이름이 `.`으로 시작하는 원격 항목이 빠집니다) · **시스템 파일 표시**(끄면 시스템 속성이 붙은 로컬 항목이 빠집니다. **기본값이 꺼짐**이라 `pagefile.sys`·`System Volume Information` 같은 항목은 켜야 보입니다). 뒤의 둘은 **속성마다 제 토글을 봅니다** — 두 속성이 함께 붙은 항목은 두 토글이 모두 켜져야 보이며, 이는 탐색기의 `숨김 파일 표시`와 `보호된 운영 체제 파일 숨기기` 조합과 같은 규칙입니다. 걸러진 뒤의 개수가 폴더·파일 개수 표시의 기준이 되고, **폴더 트리에도 같이** 적용되며 바꾸면 트리가 하위 목록을 다시 읽습니다. 켜서 보이는 숨김·시스템 항목은 **아이콘과 글자를 함께 흐리게**(불투명도 절반) 그려 보통 항목과 구분합니다 — 탐색기와 같은 표시이며 **보기 모드 8종 모두**에 적용됩니다(폴더 트리는 그대로입니다). 셋 다 **로컬·원격 목록에 같이** 적용되지만 원격 서버에는 시스템 속성이 없어 그 토글은 원격 목록을 바꾸지 않습니다. 정렬·선택·경로 조립·파일 실행은 언제나 **원래 이름**을 씁니다
  - `원격` — **원격 목록 자동 갱신**: 켜면 화면에 보이는 원격 탭의 목록을 주기마다 스스로 다시 조회합니다(아래 「원격 연결」). 그 아래 **갱신 주기**를 `10초`·`30초`·`1분`·`5분`·`10분` 중에서 고릅니다(기본 `30초`). 토글을 끄면 주기 항목이 흐려지고 **원격 재조회만** 멈춥니다 — 끊긴 네트워크 드라이브·즐겨찾기 폴더의 재확인은 서버와 무관한 로컬 일이라 그대로 계속됩니다. 그 아래 **전송 재시도 횟수**를 `1`~`10` 중에서 고릅니다(기본 `3`) — 전송이 실패했을 때 스스로 다시 걸어 볼 횟수이며, 자동 갱신 토글과 무관해 **언제나 고를 수 있습니다**
- **자동 업데이트**: 앱을 켜면 백그라운드에서 GitHub 릴리즈의 최신 버전을 **한 번** 확인합니다(시작이 느려지지 않습니다). 새 버전이 있으면 타이틀바 오른쪽에 `↓ 업데이트`가 뜨고, 누르면 `다운로드 중...`으로 바뀌며 설치 파일을 받습니다. **받는 동안에는 그 자리에 받은 비율이 함께 뜹니다**(`다운로드 중 42%`) — 서버가 전체 크기를 알려 주지 않으면 종전대로 문구만 보입니다. 다 받으면 설치 화면이 뜨고 실행 중인 앱이 스스로 닫힌 뒤 설치가 끝나면 앱이 다시 열립니다 — 그때 받아 둔 파일은 지워집니다. **받은 파일이 릴리즈에 적힌 값과 다르면 설치하지 않고 그 파일을 지웁니다.** 전송이 진행 중일 때 누르면 「지금 업데이트하면 그 전송이 중단됩니다」라고 먼저 확인합니다. 설정 메뉴(⚙)의 `업데이트`로 언제든 다시 확인할 수 있고, 이미 최신이면 그렇다고 알립니다. **설치 파일로 설치한 경우에만 동작합니다** — 빌드한 exe를 직접 실행할 때는 확인하지 않고 그 메뉴 항목도 비활성입니다
- **오픈소스 라이선스 고지**: 타이틀바 설정 메뉴(⚙)의 `오픈소스 라이선스`로 여는 대화입니다. 왼쪽에 이 앱이 쓰는 구성 요소 목록(이름·버전), 오른쪽에 고른 것의 SPDX 식별자·저작권자·**라이선스 전문**이 보입니다. `MIT OR Apache-2.0`처럼 선택형으로 선언된 것은 전문을 둘 다 싣고, 배포 패키지에 원문이 없는 것은 그 라이선스의 표준 전문을 대신 보이며 그 사유를 함께 적습니다. 크레이트가 아닌 것도 담습니다 — 정적 링크되는 **libssh2**·**zlib**과 실행 파일에 담기는 **Phosphor 글꼴**. 고지 자료는 실행 파일에 함께 들어 있어 네트워크 없이도 보이며, `cargo run --example gen_licenses`로 다시 만듭니다(의존성을 바꾸고 다시 만들지 않으면 `cargo test`가 실패합니다). **같은 명령이 레포 루트의 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)도 함께 만듭니다** — 앱을 띄우지 않고 저장소에서 바로 보는 고지이며 같은 자료를 형식만 달리 적습니다
- **앱 정보**: 타이틀바 설정 메뉴(⚙)의 `정보`로 여는 작은 팝업입니다. 가운데에 앱 아이콘(96px), 그 아래에 이름과 버전이 한 줄로 섭니다(한국어 `모아 0.1.0` / 영어 `MOA 0.1.0`). **그 아래로 저작권·라이선스·저장소 세 줄**이 작은 글씨로 서고, 저장소 줄을 누르면 브라우저가 열립니다(세 줄은 두 언어에서 같은 값입니다 — 저작권 표기·라이선스 이름·주소는 번역 대상이 아닙니다). `닫기` 버튼 하나가 있습니다. 버전은 `Cargo.toml`에서 빌드 시점에 박히므로 따로 손댈 곳이 없습니다. 아이콘은 **화면 배율에 맞는 물리 픽셀 크기로 미리 줄여** 그립니다 — 큰 그림을 그대로 올려 GPU가 줄이면 가장자리가 자글거리기 때문이며, 원본 자산은 `cargo run --example gen_app_icon`으로 다시 만듭니다
- **중복 실행 방지**: 이미 떠 있으면(창이 보이든 트레이에 숨어 있든) 새로 실행한 프로세스는 창을 만들지 않고 **기존 창을 최상위로 띄운 뒤 스스로 끝납니다** — 두 프로세스가 같은 설정 파일에 서로 덮어써 세션이 깨지는 것을 막습니다
- **자유 분할**: 패널을 **네 방향 중 원하는 쪽으로** 중첩 분할합니다 — 새 패널이 오른쪽·왼쪽·위쪽·아래쪽 어디에 놓일지 고를 수 있습니다. 진입점은 **각 패널 탭 스트립 오른쪽 끝의 패널 메뉴**(그 패널이 대상)이며, 단축키는 `Ctrl+Alt+←/→/↑/↓`입니다. 기존 `Ctrl+\`(오른쪽)·`Ctrl+Shift+\`(아래쪽)도 그대로 동작합니다. 스플리터 드래그로 비율 조절, `Ctrl+Shift+W` 패널 닫기 (마지막 1개는 닫기 불가). 분할하면 **패널마다 테두리**가 그려져 경계가 드러나고, 지금 조작 중인 패널은 더 밝은 테두리로 구분됩니다. 새 패널은 나뉜 패널과 같은 폴더에서 시작하며, 그 패널이 **원격 탭을 보고 있었으면 시작 폴더**에서 시작합니다
- **패널 메뉴**: 탭 스트립 오른쪽 끝 버튼을 누르면 그 패널을 대상으로 하는 메뉴가 열립니다 — `보기`(마우스를 올리면 보기 모드 8종이 펼쳐짐) · 네 방향 분할 · `새로 고침`(F5) · `새 파일`·`새 폴더` · `닫기`(Ctrl+Shift+W, 마지막 패널은 비활성). **상단 메뉴 바는 없습니다** — 항목이 모두 이 메뉴와 주소창·탭 스트립·사이드바에 있습니다
- **패널별 탭**: 탭 줄 오른쪽 `+`를 누르면 메뉴가 열려 `새 탭`과 **등록한 사이트 목록**(상태 점·이름·프로토콜)이 함께 나옵니다 — 사이트를 고르면 그 자리에서 원격 탭으로 열립니다. `Ctrl+T`는 메뉴를 거치지 않고 곧바로 새 탭(현재 경로 복제 — **원격 탭에서는 시작 폴더를 여는 로컬 탭**), `Ctrl+W` 탭 닫기(마지막 탭은 패널 닫기로 연결), 탭 클릭 전환, 탭별 독립 히스토리. 탭 하나에 **폴더 아이콘·이름·닫기(×)**가 함께 들어 있고(가운데 버튼 클릭으로도 닫힙니다), 활성 탭만 배경으로 강조됩니다. 탭이 많으면 탭 영역만 가로로 스크롤되고 분할 버튼은 오른쪽 끝에 남습니다
- **보기 모드 8종**: `아주 큰 아이콘`(256px) · `큰 아이콘`(96px) · `보통 아이콘`(48px) · `작은 아이콘`(16px) · `목록` · `자세히` · `타일` · `내용`. 패널 메뉴의 `보기`에 마우스를 올리면 펼쳐지고 현재 모드에 점이 붙습니다. **작은 아이콘은 왼→오른쪽, 목록은 위→아래로** 채워 서로 다르게 흐릅니다. 모드는 패널마다 독립이며 세션에 저장됩니다
- **썸네일 미리보기**: 아이콘 4종·타일·내용 보기에서 사진·동영상·문서의 **실제 미리보기**를 보입니다(`IShellItemImageFactory`). 워커 스레드가 만들고 준비 전에는 형식 아이콘을 보여주며, 패널당 최근 200장(약 50MB)만 들고 폴더를 떠나면 즉시 놓습니다. 자세히·목록 보기는 16px 형식 아이콘을 유지합니다. **미리보기는 원본 비율을 지켜 아이콘 자리 안에 들어갑니다** — 탐색기와 같은 규칙이라 가로가 긴 사진은 위아래가 남고, 정사각형으로 늘어나지 않습니다(형식 아이콘은 본래 정사각형이라 자리를 그대로 채웁니다). **자리보다 작은 그림은 키우지 않고 원본 크기로** 가운데에 놓습니다 — 이것도 탐색기와 같으며, 화면 배율을 따져 물리 픽셀 1:1을 넘기지 않습니다. 미리보기와 아이콘 모두 **밉맵을 만들어 올려** 큰 그림(256px)을 작은 자리에 줄여 그릴 때도 가장자리가 자글거리지 않습니다
- **파일 목록**: 자세히 보기는 이름·크기·종류·수정한 날짜 4열이며 **열 경계를 끌어 폭을 조절**할 수 있습니다(패널마다 독립·세션 저장). 머리글의 열 경계마다 **세로 구분선**이 서 있어 어디를 잡을지 보이고, 끄는 동안에는 그 경계가 목록 바닥까지 강조색으로 이어집니다. 열 폭 합이 패널보다 넓으면 가로로 스크롤되고, 폭을 넘는 글자는 모든 열에서 `…`로 줄여 한 줄로 보입니다. **크기는 소수점 둘째자리까지 KB·MB·GB로** 보입니다(`1.00 KB`·`1.18 MB` — 폴더는 빈 칸). 열 클릭 정렬(탐색기와 동일한 숫자 인지 정렬·폴더 우선)이며 **정렬 기준과 방향은 패널마다 세션에 저장돼 재시작 뒤에도 남고, 보기 모드를 바꿔도 유지됩니다**. **열 머리글의 가운데를 끌면 열 차례가 바뀝니다**(놓일 자리에 세로선이 서고, 경계선 근처를 끌면 종전대로 폭 조절입니다 — 잡는 자리로 갈립니다). 바뀐 차례도 패널마다 저장되며 각 열의 폭은 그 열을 따라 움직입니다. 시스템 아이콘, 보이는 것만 그리는 가상 스크롤 + 백그라운드 열거(대량 폴더 UI 무정지). **다 읽었는데 항목이 하나도 없으면 `이 폴더는 비어 있습니다`**가 목록 자리에 서고(끌어다 놓기는 그대로 받습니다), **아직 아무것도 읽지 못한 채 읽는 중일 때는 목록 자리에 자리표시 8줄**이 서고 목록 위에 `읽는 중…`이 붙습니다 — 이미 목록이 있는 폴더에서 다른 폴더로 옮기는 중이라면 종전 목록이 그대로 남습니다. **최근에 읽어 둔 폴더로 다시 가면 그때의 목록이 즉시 서고**(자리표시가 뜨지 않습니다) 주소창·히스토리도 함께 옮겨진 뒤, 뒤에서 도는 실제 열거가 끝나면 그 결과로 갈아 끼워집니다 — 그동안 목록은 **잠깐 낡아 있을 수 있습니다**(폴더를 떠난 뒤의 변경은 감시하지 않으므로, 다른 앱이 그 사이에 만든 파일은 갱신이 도착해야 나타납니다). 담아 두는 것은 최근 8폴더·폴더당 5000항목까지이며, 그보다 큰 폴더는 담지 않는 대신 **다 읽기 전에 먼저 보입니다** — 첫 2000항목이 정렬된 채 서고 나머지는 읽히는 대로 그 사이에 끼어듭니다. 옮겨 간 폴더가 그새 사라졌으면 **원래 자리로 되돌아갑니다**(앞으로 가기 목록도 그대로 남습니다)
- **새로 만들기**: 패널 메뉴의 `새 폴더`(`Ctrl+Shift+N`)·`새 파일`로 표시 중인 폴더에 만듭니다. 이름이 겹치면 `(2)`, `(3)`… 번호가 붙고 **기존 항목을 덮어쓰지 않습니다**. 만들기는 워커 스레드에서 수행하며 실패하면 사유가 목록 위에 표시됩니다
- **끌어다 놓아 복사**: 로컬 탭에서 고른 파일·폴더를 **다른 로컬 탭에 놓으면 그 폴더로 복사**됩니다. **끌어온 자리에 그대로 놓으면 아무 일도 일어나지 않습니다** — 사본(`- 복사본`)을 만들지 않고 알림도 뜨지 않습니다(다른 탭이 같은 폴더를 보고 있을 때도 같습니다). 앱 **안**에서 끄는 동안에는 **고른 것 중 첫 항목의 반투명 그림**이 커서를 따라옵니다 — 이미 만들어져 있는 미리보기가 있으면 그것이고 없으면 그 파일의 형식 아이콘이며, 여러 개를 끌어도 한 장입니다. **바탕화면·윈도우 탐색기에서 끌어온 것도 같은 방식으로 받습니다** — 로컬 탭에 놓으면 복사, 원격 탭에 놓으면 올리기가 됩니다(끌고 창 위를 지나는 동안 놓일 패널의 테두리가 강조되고, 패널 밖에 놓으면 아무 일도 일어나지 않습니다). 이쪽은 **탐색기에서 같은 폴더로 끌어와도 종전대로 Windows가 복사**합니다 — 위의 "그대로 놓으면 아무 일도 없음"은 앱 안에서 끄는 경우입니다. 반대로 **로컬 탭에서 끌어 창 밖의 탐색기·바탕화면에 놓으면 그 자리로 복사**됩니다(원격 항목은 대상이 아닙니다) — 창 밖으로 끄는 동안에는 **고른 것 중 첫 항목의 그림**과 `복사 → 대상` 문구가 커서를 따라옵니다(이미 만들어져 있는 미리보기가 있으면 그것이고, 없으면 그 파일의 형식 아이콘입니다). 그림이 뜨지 않아도 복사는 그대로 됩니다. **언제나 복사이며 이동하지 않습니다** — 보조키로 동작이 갈리지 않아 원본이 사라질 일이 없습니다. 복사 자체는 **Windows가 합니다** — 진행률 창·같은 이름 충돌 확인·`Ctrl+Z` 되돌리기·권한 승격이 모두 탐색기에서 복사할 때와 같고, 탈이 났거나 그만두면 그 사실만 상태 줄에 알립니다
- **탐색**: 주소창 경로 입력(Enter), 뒤로/앞으로/상위(`Alt+←/→/↑`), **마우스 옆의 뒤로·앞으로 버튼**(탐색기와 같습니다 — 활성 패널에 적용됩니다), 더블클릭 폴더 진입·파일 실행, 잘못된 경로 입력 시 현 위치 유지. **목록 첫 줄의 `..`를 더블클릭해도 위 폴더로 갑니다** — 로컬·원격 목록 모두에 있으며, 올라갈 곳이 없는 드라이브 루트(`C:\`)에서는 나오지 않습니다
- **이름으로 거르기**: 주소창 오른쪽 입력란에 글자를 치면 **지금 보고 있는 폴더**의 목록에서 그 글자를 이름에 담은 항목만 남습니다. 대소문자를 가리지 않고 이름 어디에 있어도 걸리며, 확장자 표시를 꺼 두었어도 **원래 이름**으로 견줍니다(`txt`를 치면 확장자가 안 보이는 상태에서도 걸립니다). 로컬·원격 목록 둘 다에서 되고 **패널마다 따로** 걸립니다. 맨 위 `..` 줄은 언제나 남아 있어 필터를 켠 채로도 위로 올라갈 수 있습니다. 폴더를 옮기거나 탭을 바꾸면 입력란이 비워지며(필터가 켜진 채로 다른 폴더에 가면 빈 폴더처럼 보이기 때문입니다) 재시작 뒤에는 남지 않습니다. 같은 폴더를 다시 읽는 경우(변경 감시·`F5`·숨김 표시 토글)에는 치던 글자가 그대로 있습니다. **하위 폴더까지 훑는 검색은 하지 않습니다.**
- **폴더 트리**: 패널별 토글(상태 줄 왼쪽 끝의 트리 아이콘 버튼 — 마우스를 올리면 `폴더 트리`/`원격 트리`가 뜹니다) — 드라이브 루트에서 지연 확장(하위 1단계만 워커 열거), 노드 클릭 시 활성 탭 이동 (단방향). 줄마다 **탐색기와 같은 셸 아이콘**이 붙고 드라이브는 `로컬 디스크 (C:)` 같은 **셸 표시 이름**으로 보입니다(이름을 얻지 못하면 `C:\` 같은 경로로 보입니다). 원격 트리는 서버에서 아이콘을 얻을 수 없어 모든 줄이 같은 폴더 아이콘입니다. **닿지 못하는 네트워크 드라이브 줄에는 아이콘 오른쪽 아래에 연결 끊김 표식(빨간 원 안의 흰 X)이 겹칩니다** — 탐색기와 같은 표시이며 누르기 전에도 보입니다(로컬 드라이브와 닿는 네트워크 드라이브에는 붙지 않습니다). 이 판정은 앱이 뜰 때와 **그 뒤 30초마다** 워커가 다시 하고, 그 드라이브를 열어 볼 때도 갱신됩니다 — 연결이 되살아나면 다음 확인에서 표식이 저절로 사라지고, 끊기면 저절로 붙습니다(앞선 확인이 아직 돌고 있으면 새로 띄우지 않습니다). 이 확인은 설정의 원격 목록 자동 갱신을 꺼도 계속됩니다 — 서버에 묻지 않는 로컬 일입니다
- **즐겨찾기**: 로컬 폴더 트리 **맨 위**에 `즐겨찾기` 제목과 함께 자주 쓰는 폴더를 모아 둡니다. **`바탕 화면`·`다운로드`는 처음부터 맨 위에 서 있고 뺄 수 없습니다**(그 줄은 우클릭해도 메뉴가 뜨지 않습니다. 폴더를 옮겼어도 윈도우에 물어 옮긴 자리를 가리키며, 그 폴더가 없는 PC에서는 해당 줄만 빠집니다). 트리 항목을 우클릭해 `즐겨찾기에 담기`로 담고(이미 담긴 폴더면 그 메뉴가 흐리게 보입니다), 사용자가 담은 즐겨찾기 줄을 우클릭해 `해제`로 뺍니다. 목록과 아래 트리 사이에는 가로 구분선이 서고, **하나도 없으면 제목도 목록도 구분선도 나오지 않습니다**. 사용자가 담은 항목은 폴더 이름으로, 기본 두 줄은 윈도우가 쓰는 이름(`바탕 화면`)으로 보이며 마우스를 올리면 전체 경로가 뜨고, 누르면 활성 탭이 그 폴더로 갑니다. **목록은 앱에 하나뿐이라 모든 워크스페이스·패널·탭이 같은 것을 보고** 재시작해도 남습니다. **사용자가 담은 항목은 끌어서 차례를 바꿀 수 있고**(놓일 자리에 가로선이 서며, 조금 움직인 것은 클릭으로 처리돼 그 폴더로 갑니다) 바뀐 차례도 저장됩니다 — 기본 두 줄은 끌리지 않고 그 위로 놓을 수도 없습니다. **가리키는 폴더가 사라진 항목은 흐린 글씨로 남고 눌러도 이동하지 않습니다** — 자동으로 지우지 않으므로 잠시 끊긴 네트워크·USB 폴더가 조용히 사라지지 않고, 다시 생기면 정상으로 돌아옵니다(우클릭 `해제`로 직접 뺄 수 있습니다). 이 확인도 30초마다 워커가 합니다. **원격 트리에는 즐겨찾기가 없습니다**

- **원격 연결 (FTP·FTPS·SFTP)**: 사이드바 `+`(연결 메뉴)나 사이트 관리자에서 사이트를 등록해 **원격 탭**을 엽니다. 원격 탭은 로컬 탭과 같은 자리에서 같은 목록·정렬·보기 모드를 쓰며, 탭 배지가 연결 단계(`연결 없음`·`연결 중…`·프로토콜 이름)를 보입니다. 주소창에 `ftp://`·`sftp://` 주소를 넣어 바로 열 수도 있습니다. 사이드바에 사이트가 하나도 없으면 그 자리에 `+ 를 눌러 서버를 등록하세요`가 서고, 사이트 행 우클릭의 **`삭제`**는 목록에서 빼는 동시에 **그 사이트의 연결을 끊고 그 사이트를 가리키는 원격 탭을 닫으며 전송 큐 항목도 지웁니다** — 그래서 하단 전송 큐 화면의 연결별 탭에서도 그 서버가 곧바로 사라집니다. 진행 중이거나 기다리는 전송이 있을 때만 확인을 받고, 없으면 바로 지웁니다. **사이트 자체는 사이트 관리자에 그대로 남아** 다시 연결할 수 있습니다(지운 뒤 그 사실을 알리는 알림이 뜹니다). 연결에 실패하면 서버가 준 사유와 함께 **그 실패에 맞는 안내**가 붙고(연결 실패면 암호화 설정, 로그인 거절이면 사용자 이름·비밀번호, 지문 문제면 지문 확인), 주 동작인 `재시도`가 굵게 강조됩니다. **화면에 보이는 원격 탭은 목록을 주기마다 스스로 다시 조회합니다**(기본 30초 — 설정의 `원격` 묶음에서 끄거나 주기를 바꿉니다). 서버가 변경을 알려 주는 감시가 아니라 **다시 묻는 것**입니다. **전송이 도는 중과 그 패널을 막 조작한 직후에는 건너뛰고**, 조회 결과가 직전과 같으면 목록을 갈아 끼우지 않아 고른 항목과 스크롤이 흔들리지 않습니다(달라졌으면 갈아 끼우되 고르던 것을 이름으로 되살립니다). **이 조회는 서버 로그에 성공 기록을 남기지 않고 실패만 남깁니다** — 30초마다 두 줄씩 쌓이면 사용자가 실제로 한 조작의 기록이 밀려나기 때문이며, 같은 이유로 그 실패는 화면 알림도 띄우지 않습니다
- **사이트 관리자**: 이름·프로토콜(FTP/FTPS/SFTP)·호스트·포트·로그온 유형(익명/일반/키 파일)·사용자·비밀번호·**키 파일 경로와 키 암호**·전송 모드·동시 연결 수 제한·문자 인코딩을 다룹니다. **비밀번호와 키 암호는 Windows DPAPI로 봉인해** 저장하며 파일에는 평문이 남지 않습니다. DPAPI는 이 PC·이 계정에 묶여 있어 설정 파일만 복사해서는 다른 PC에서 비밀번호가 풀리지 않는데, **그럴 때는 아래 `내보내기`를 쓰면 됩니다**. **SFTP는 개인 키 파일로도 접속합니다** — 로그온 유형에서 `키 파일`을 고르면(그 선택지는 **SFTP를 골랐을 때만** 보입니다) 키 파일 경로와 키 암호 칸이 열리고 비밀번호 칸이 잠깁니다. 경로는 `찾아보기`로 고르며, 암호를 걸지 않은 키는 암호 칸을 비워 두면 됩니다. 인증에 실패하면 서버가 준 사유를 그대로 보입니다. **로그온 유형을 바꿔 저장하면 그 수단에 쓰지 않는 비밀은 지워집니다** — 키 파일로 바꾸면 담아 둔 비밀번호가, 비밀번호로 되돌리면 키 경로와 키 암호가 사라집니다. 에이전트(Pageant·OpenSSH) 인증은 지원하지 않습니다. SFTP는 서버 지문을 처음 볼 때 확인을 받고, 지문이 바뀌면 경고합니다. **`삭제(D)`는 확인 대화를 거칩니다** — 주소와 로그인 정보가 함께 사라지고 되돌릴 수 없기 때문입니다. 전송 모드 세 선택지(`기본`·`능동형`·`수동형`)에는 무슨 일이 일어나는지 알려 주는 설명이 툴팁으로 붙습니다. **목록 아래 `새 사이트`를 누르면 빈 항목이 곧바로 목록에 생기고** 오른쪽 칸이 그 항목을 가리킵니다 — 주소를 적어 `확인(O)`을 눌러야 등록이 끝나며, **주소를 적지 않은 항목은 사이드바 연결 목록·`+` 연결 메뉴·새 탭 메뉴에 서지 않습니다**(붙을 곳이 없어 골라도 연결되지 않기 때문입니다). 그런 항목도 사이트 관리자 목록에는 그대로 남아 나중에 이어서 채울 수 있고, 지우려면 `삭제(D)`를 씁니다. **목록은 끌어서 차례를 바꿉니다** — 놓일 자리에 가로선이 그어지고, 그 차례가 곧 사이드바에 서는 차례이자 다시 켜도 남는 차례입니다. **사이트가 많아 목록 칸을 넘치면 스크롤됩니다.** **목록의 항목을 더블클릭하면 그 자리에서 이름을 고칩니다.** **항목을 오른쪽 버튼으로 누르면 `이름 바꾸기`·`삭제`·`복사` 메뉴가 뜨고**, 누른 항목이 함께 골라집니다 — 셋은 위 버튼 줄과 같은 일을 합니다(`복사`는 `복제(I)`와 같이 사이트를 하나 더 만듭니다). **목록 칸의 빈 자리를 오른쪽 버튼으로 누르면 `새 사이트`·`내보내기`·`가져오기` 메뉴가 뜹니다** — 아래 버튼 줄과 같은 일이며, 등록된 사이트가 없으면 `내보내기`는 잠깁니다

- **전송 큐**: 목록 사이 **끌어다 놓기**(로컬 ↔ 원격, 폴더는 하위까지 펼쳐서)와 원격 메뉴의 `받기`·`올리기`로 큐에 담깁니다. 끄는 동안에는 로컬끼리의 복사와 마찬가지로 **첫 항목의 반투명 그림**이 커서를 따라옵니다(원격 항목은 미리보기가 없어 형식 아이콘입니다). **전송이 끝나면 그 폴더를 보고 있는 원격 목록이 저절로 다시 - **탐색기 단축키**: `Ctrl+Shift+N` 새 폴더 · `Alt+←` 뒤로 · `Alt+→` 앞으로 · `Alt+↑` 상위 폴더 · `F5` 새로 고침 · `F2` 이름 변경 · `Delete` 휴지통으로 · `Shift+Delete` 영구 삭제 · `Ctrl+C` 복사 · `Ctrl+X` 잘라내기 · `Ctrl+V` 붙여넣기. **마우스에 옆 버튼이 있으면 그 둘도 뒤로·앞으로로 동작합니다.** 여기에 앱 고유의 `Ctrl+T`/`Ctrl+W`(탭)·`Ctrl+Alt+←/→/↑/↓`(분할)·`Ctrl+Shift+W`(패널 닫기)·`Ctrl+B`(사이드바)가 더해집니다. **`F2`·`Delete`는 마지막으로 누른 영역이 받습니다** — 사이드바 카드를 누른 뒤 `F2`는 워크스페이스 이름 편집이고, 파일 목록을 누른 뒤라면 파일이 대상입니다(워크스페이스 삭제에는 키를 배정하지 않았습니다 — 사이드바 우클릭 메뉴로 지웁니다)
- **세션 저장/복원**: **무엇이 바뀌든 곧(0.4초 안에) 저장합니다** — 종료를 기다리지 않아 강제 종료·전원 차단에도 남습니다. 담기는 것은 워크스페이스 목록·각 워크스페이스의 분할 구성과 탭(로컬 경로·**원격 사이트와 경로**)·**패널별 보기 모드와 열 폭·정렬 기준과 방향·열 차례**·**전송 큐 표의 열 폭·차례·끈 열(탭마다 한 벌씩)**·사이드바 폭/접힘·창 위치/최대화에 더해 **등록한 사이트·끝나지 않은 전송 큐(시작·완료 시각까지)·도크의 큐 필터**를 **실행 파일과 같은 폴더의** `settings.json`에 저장, 재시작 시 복원합니다. **다만 하단 도크가 열려 있었는지는 저장하지 않습니다** — 앱은 언제나 도크가 닫힌 채로 시작하며(다시 열면 보던 필터와 열 폭이 그대로입니다), 트레이로 숨겼다 다시 부를 때는 같은 실행이라 보고 있던 그대로입니다. **재시작해도 서버에 자동으로 연결하지 않고 전송도 스스로 재개하지 않습니다** — 원격 탭은 `연결 없음`으로, 큐는 대기·실패인 채로 섭니다. 되살아난 원격 탭은 **`다시 연결` 버튼**을 보이며, 누르면 그 사이트로 붙어 저장된 폴더의 목록을 바로 보입니다(사이트를 지운 뒤 남은 탭은 붙을 곳을 모르므로 종전대로 주소 입력 안내를 보입니다). **화면이 여럿이면 지난번 그 화면에 되살립니다** — 화면마다 배율이 달라도 창이 있던 쪽을 찾아 그 화면의 작업 영역만 하게 띄우고, 그 화면을 뽑았거나 배치가 바뀌어 저장된 자리가 어디에도 없으면 주 화면 안으로 들여옵니다. 옛 형식(v2) 파일은 그대로 승격되어 살아납니다. 재시작 직후에는 **활성 워크스페이스의 탐색기만 생성**하고 나머지는 선택할 때 만듭니다(메모리 절약). 손상·구버전 파일은 기본 레이아웃으로 폴백합니다
- **다크 테마**: 창 전체(타이틀바·파일 목록·폴더 트리·주소창·탭·워크스페이스 사이드바)를 고정 다크 스타일로 표시합니다(전환 UI 없음). 타이틀바는 앱이 직접 그리고, 패널 메뉴 팝업도 앱 팔레트를 따릅니다. 우클릭 셸 메뉴는 Windows 다크 정책을 따릅니다
- **팝업 공통 규격**: 확인·입력 대화부터 설정·사이트 관리자까지 **모든 팝업이 같은 모양**입니다 — 네 모서리가 둥글고(12px), 하단 버튼은 팝업 좌우 끝까지 닿아 개수만큼 균등하게 나뉘며 그 사이를 가는 구분선이 가릅니다. 마우스를 올린 칸만 배경이 밝아지고, 그 대화의 주 동작(`확인`·`삭제`·`연결` 등)은 글자가 굵습니다. 본문은 버튼 줄에서 한 칸 떨어져 있어 목록·표의 테두리가 버튼 구분선과 겹쳐 보이지 않습니다. 글자를 받는 팝업(`이름 바꾸기`·`새 폴더`·`권한 변경`의 8진수 칸)의 입력칸은 **테두리를 두른 어두운 웰**이라 포커스가 없어도 어디에 입력하는지 보이며, 사이트 관리자 폼의 입력 필드와 같은 규격입니다. 이 규격은 `src/ui/dialog.rs` 한 곳에 있어 앞으로 더할 팝업도 자동으로 같은 모양이 됩니다. **우클릭 메뉴·드롭다운은 별도 부품**으로, 모서리를 6px로 통일해 두었습니다 — 값의 정본은 `src/ui/theme.rs` 한 곳이라 메뉴마다 따로 적지 않아도 같은 모양이 됩니다
- **한국어·영어 UI**: 화면 문구는 한 곳(`src/i18n`)의 카탈로그를 거칩니다 — 키 하나에 두 언어를 함께 적고, 한쪽을 빠뜨리면 컴파일되지 않습니다. 서버가 보낸 응답 원문(`530 Login incorrect` 등)과 FTP 명령어는 번역하지 않고 그대로 싣습니다
- 긴 경로(260자+)·유니코드 파일명, Per-Monitor v2 DPI

## 실행 방법

```
cargo run              # 디버그 실행
cargo build --release  # 배포 빌드 (단일 exe, 약 8.6MB)
```

요구 사항: Rust stable(1.80+, msvc 툴체인), Windows 11 이상.

검증: `cargo test`(단위테스트), `cargo clippy --all-targets -- -D warnings`, `cargo fmt --check`

### 설치 파일 만들기

```
winget install NSIS.NSIS          # 처음 한 번 (설치 파일 생성 도구)
cargo build --release
cargo run --example gen_installer # → target/installer/MOA-Setup-<버전>.exe
```

NSIS가 없으면 그 안내와 함께 실패로 끝납니다(빈 결과를 성공으로 알리지 않습니다). `cargo build --release`를 건너뛰어 `target/release/moa.exe`가 소스보다 낡았을 때도 같은 방식으로 멈춥니다.

### 설치 파일로 설치할 때

- **관리자 권한을 묻지 않습니다** — `%LOCALAPPDATA%\Programs\MOA`에 사용자 단위로 설치합니다. **설치 폴더는 고를 수 없습니다** — 설치 위치 화면은 종전대로 보이지만 경로 입력란과 「찾아보기」가 잠겨 있습니다.
- **설치를 시작하면 실행 중인 MOA를 자동으로 닫습니다** — 먼저 정상 종료를 청해 설정을 저장할 틈을 주고, 트레이에 남아 있으면 강제로 닫습니다. 설치하는 동안 확인 팝업은 뜨지 않습니다.
- **설치 화면에 보이는 앱 이름은 고른 언어를 따릅니다** — 한국어면 창 제목이 `모아 <버전> 설치`가 되고 바로가기 이름도 `모아`, 영어면 `MOA`입니다. 맨 처음 뜨는 **언어 선택 창의 문구는 Windows 표시 언어**를 따르며, 거기서 고른 언어는 그 다음 화면부터 반영됩니다(고르는 순간 그 창이 다시 그려지지는 않습니다). **제거할 때는 언어를 묻지 않습니다** — 고를 것이 없어 Windows 표시 언어를 그대로 씁니다.
- 시작 메뉴에 바로가기가 만들어지고, 바탕화면 바로가기는 마지막 화면의 체크박스로 고릅니다.
- **설정과 서버 지문 파일이 설치 폴더 안에 생깁니다**(`settings.json`·`known_hosts.json`). 재설치·덮어쓰기로는 지워지지 않습니다.
- **제거하면 묻지 않고 설정과 지문 파일까지 함께 지웁니다** — 사이트 목록·저장한 비밀번호·서버 지문이 사라집니다(설치 첫 화면에서 이 사실을 미리 알립니다). 자동 실행을 켜 뒀다면 그 등록도 함께 걷습니다. 지우는 것은 **설치 프로그램과 앱이 만든 파일뿐**이라, 그 폴더에 따로 넣어 둔 파일이 있으면 폴더째 남습니다.
- **설치본은 새 버전을 스스로 찾아 받습니다**(위 「자동 업데이트」). 업데이트로 설치할 때는 언어·환영·라이선스·폴더 화면을 건너뛰고 진행 화면만 보인 뒤 앱이 다시 열립니다.
- 코드 서명은 없습니다.

핵심 플로우: 탐색 요청 → `PanelState::navigate`(pending 등록, 세대 번호 증가) → 워커 스레드 열거 → 채널 수신 후 프레임에서 반영 → 경로·히스토리 커밋 → 커밋된 폴더로 변경 감시 교체. **폴더를 열지 못했을 때도 그 폴더까지 옮깁니다** — 주소창·트리와 목록이 갈리지 않도록 경로는 커밋하되 목록을 비우고 그 자리에 사유를 적으며(올라갈 곳이 있으면 첫 줄 `..`만 남습니다 — 드라이브 뿌리에는 그 줄도 없습니다), 읽지 못한 폴더는 감시하지 않습니다. 사유는 세 갈래로 갈라 적습니다: `이 폴더를 열 권한이 없어 내용을 표시할 수 없습니다` / `네트워크 드라이브에 연결할 수 없어 내용을 표시할 수 없습니다` / `이 폴더를 여는 중 문제가 생겨 내용을 표시할 수 없습니다`. **폴더를 찾을 수 없는 경우만** 현 위치·목록을 지키고 상태 줄에 사유를 알립니다(실재하지 않는 곳에는 옮길 자리가 없습니다). 컨텍스트 메뉴는 **셸에게 항목을 물어 앱이 그립니다** — `IContextMenu::QueryContextMenu`가 채운 HMENU를 읽어 우리 모델로 옮기고(라벨·아이콘·활성·하위 메뉴), **탐색기 차례의 표준 항목과 `앱 확장`·`다음으로 압축`·`압축 풀기` 묶음으로 갈라 세운 뒤**, 고른 항목은 다시 셸의 `InvokeCommand`로 돌려보냅니다. **`다음으로 압축`의 첫 줄만 다른 길로 갑니다** — Windows 기본 압축은 메뉴로 오지 않아 `SendTo` 폴더의 그 항목을 `IDropTarget`으로 얻어 넘깁니다(`fs::zip_shell`). 재정렬해도 아이콘은 셸이 준 원래 자리로 찾습니다. 하위 메뉴는 처음 펼칠 때 `WM_INITMENUPOPUP`을 확장에 전달해 채웁니다. `기본 메뉴`가 여는 표준 메뉴는 자체 메시지 루프를 돌리므로 프레임 그리기가 모두 끝난 뒤에 띄웁니다. 파일 작업 자체는 여전히 셸이 합니다 — 이름 바꾸기·삭제·복사·이동은 `IFileOperation`에 걸어 워커 스레드에서 돌리고(확인·진행률 대화는 Windows가 띄웁니다), 클립보드는 Windows 표준 형식을 그대로 씁니다. 종료 시 세션 수집·저장, 시작 시 복원.

원격 플로우: 사이트 선택 → 워커 스레드 하나가 그 연결을 맡고(탐색 1 + 전송 N채널), 화면은 **채널만 폴링**합니다 — 서버가 응답하지 않아도 다른 패널·다른 사이트는 계속 움직입니다. 목록·전송·파일 작업은 전부 명령으로 나가고 결과는 이벤트로 돌아옵니다. **목록 조회 요청은 자기 출처를 들고 다닙니다** — 패널(워크스페이스·패널 자리와 일련번호)·원격 트리·같은 이름 확인 셋으로 갈라져, 답이 청한 곳으로 정확히 돌아가고 늦게 온 지난 요청의 답은 그 일련번호로 걸러집니다. 같은 사이트를 두 패널에 나란히 열어도 한쪽의 실패가 다른 쪽을 되돌리지 않습니다. 전송은 64KB씩 흘려보내 파일 크기와 무관하게 메모리가 버퍼 몫에 머물고, 끊기면 `.part`의 크기에서 이어받습니다.

워크스페이스 플로우: 사이드바 클릭 → 그 워크스페이스가 활성이 되고, **처음 선택이면** 저장된 구성으로 분할·탭을 만듭니다(지연 생성 — 방문하지 않은 워크스페이스는 패널도 열거 스레드도 없습니다). 이미 만든 워크스페이스는 상태를 그대로 갖고 있어 스크롤·선택이 유지됩니다. 활성 패널의 폴더가 바뀌면 사이드바 카드의 둘째 줄이 따라 갱신됩니다.
